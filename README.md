# Gavana plugin

Use [Gavana](https://gavana.ai) from ChatGPT and Codex: make posts, ads and videos on your Gavana canvas with Gavana skills and hosted MCP tools.

## What's inside

| Path | What it is |
| --- | --- |
| `plugin.json`, `.codex-plugin/plugin.json` | Plugin manifests |
| `mcp.json`, `.mcp.json` | The hosted Gavana MCP server, `https://app.gavana.ai/mcp` |
| `skills/` | `gavana-campaign`, `gavana-cli`, `gavana-reference-images`, `gavana-work` |
| `assets/` | Logo |
